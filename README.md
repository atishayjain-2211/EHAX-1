# EHAX-1 In Memory Database
I built this project to understand how to create a database based on dictionary. <br>
It stores, retrieves, establishes, finds what already exists, saves, deletes any data given to the database.<br>
It takes the input from the user and operates accordingly.<br>
I have included SET, GET, DEL, EXISTS, SAVE. <br>
Error handling - For any invalid input from user it prevents the program from terminating when file doesn't exist. <br>
I used text file to create database memory. <br>
